CHAPTER 22 — ELGENE
===================

Open index.html with VS Code Live Server.

Project structure:
index.html
style.css
script.js
images/
music/ke-lorile.mp3

The site is designed mobile-first and uses all seven supplied photographs.

TO REPLACE THE SONG LATER:
The current soundtrack is Ke Lorile by Pleasure Tsa Manyalo. If you ever replace it, keep the filename music/ke-lorile.mp3 or update index.html.

TO PUBLISH WITH GITHUB PAGES:
Upload index.html, style.css, script.js, images/ and music/ to the ROOT of the repository.
Then Settings > Pages > Deploy from a branch > main > /(root).
